# SOM Solver

**Strength of Materials AI Powered Problem Solver**

Solve any Strength of Materials problem with step-by-step solutions powered by Google Gemini API.

## Features

✨ **AI-Powered Solutions** - Get detailed, step-by-step solutions  
📋 **Comprehensive Coverage** - Stress, strain, beams, torsion, columns, Mohr's circle, etc.  
🎯 **Structured Answers** - Given data, formulas, calculations, and concept explanations  
📱 **Responsive Design** - Works on desktop, tablet, and mobile  
🚀 **Instant Results** - Real-time problem solving with Google Gemini API  

## Getting Started

### Prerequisites
- A free Google Gemini API key from [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)

### How to Use

1. **Get your API Key**
   - Visit [Google AI Studio](https://aistudio.google.com/app/apikey)
   - Create a free API key
   - Copy and paste it in the app

2. **Ask Your Question**
   - Enter your Strength of Materials problem
   - Or use one of the preset examples

3. **Get Your Solution**
   - Click "Solve Step-by-Step"
   - View the detailed solution with all calculations

## Example Problems

- **Axial Stress**: A steel rod of 20 mm diameter and 2 m length is subjected to an axial pull of 40 kN. Find stress, strain and elongation.
- **Bending Equation**: Derive M/I = σ/y = E/R
- **Shear Force & Bending Moment Diagram**: Analyze simply supported beams
- **Mohr's Circle**: Understand stress transformation

## Technologies Used

- **Frontend**: HTML5, Tailwind CSS
- **AI**: Google Gemini 1.5 Flash API
- **Markdown**: Marked.js for rendering solutions

## Deployment

This app is deployed on **GitHub Pages** and is fully static. Just open `index.html` in your browser or visit the live demo.

### Deploy Your Own

1. Fork this repository
2. Enable GitHub Pages in repository settings
3. Set source to `main` branch
4. Your app will be live at `https://yourusername.github.io/som-solver`

## Important Notes
